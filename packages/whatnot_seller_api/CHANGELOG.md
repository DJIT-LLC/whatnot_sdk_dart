## 0.1.0

- Initial release.
- REST v2 client with automatic rate-limit retries (`RateLimit-*`, `Retry-After`) and RFC 9457 Problem Details error translation.
- Cryptographic HMAC-SHA256 Webhook signature verification and typed event dispatcher.
- Generated models and API resources from the official Whatnot OpenAPI 3.1.0 specification using `analyzer_buffer` and Dart 3.13 Primary Constructors.
